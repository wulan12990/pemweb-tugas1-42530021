## Deskripsi Proyek

Website ini merupakan portofolio profesional sederhana yang dibuat untuk menampilkan
profil, kemampuan, pengalaman pembelajaran, serta beberapa proyek yang pernah
dikerjakan dalam bidang teknologi informasi.

Website dirancang menggunakan HTML5 semantik dan CSS modern dengan pendekatan
mobile-first sehingga dapat menyesuaikan tampilan pada berbagai ukuran layar.

---

## Tujuan

Tujuan pembuatan website ini adalah:

1. Menerapkan struktur HTML5 semantik.
2. Menerapkan CSS modern menggunakan Flexbox dan CSS Grid.
3. Membuat website yang responsif pada perangkat mobile, tablet, dan desktop.
4. Menerapkan dasar-dasar aksesibilitas web.
5. Menampilkan portofolio dan kemampuan di bidang teknologi informasi.
6. Menerapkan struktur proyek web yang rapi dan terorganisir.

---

## Fitur Website

Website memiliki beberapa bagian utama, yaitu:

### 1. Beranda

Menampilkan identitas singkat, status sebagai mahasiswa Teknologi Informasi,
fokus pembelajaran, serta tombol Call to Action (CTA).

### 2. Tentang Saya

Berisi informasi singkat mengenai latar belakang dan minat di bidang teknologi
informasi serta nilai atau prinsip yang diterapkan dalam proses belajar.

### 3. Proyek Unggulan

Menampilkan beberapa proyek pembelajaran, yaitu:

- SmashCourt System
- Website Informasi Akademik
- Bali Digital Store Network

### 4. Teknologi yang Dipelajari

Menampilkan teknologi dan tools yang dipelajari, antara lain:

- HTML5
- CSS3
- Java
- MySQL
- Git & GitHub
- UI & Web Design

### 5. Pendidikan & Pengembangan

Menampilkan latar belakang pendidikan sebelumnya dan pendidikan saat ini,
serta prinsip belajar dalam mengembangkan kemampuan teknologi.

### 6. Kontak

Menyediakan informasi untuk terhubung melalui email, GitHub, dan LinkedIn.
